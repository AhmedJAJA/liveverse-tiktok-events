# LIVEVERSE — TikTok LIVE Events Studio

Live interactive events for TikTok streams: quiz, guessing, race, wheel, points leaderboard and OBS overlay.

This repository is being initialized with the tested v0.1 source code. For setup, use `npm install`, set `ADMIN_TOKEN` in the environment, then `npm start`. Use `npm test` to run the 31 automated game-engine tests.

The TikTok integration uses an unofficial connector and requires testing against a real live stream.
